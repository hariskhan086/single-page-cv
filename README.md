# Single-Page CV

A single-page CV website created using HTML.

## Technologies Used

* HTML5

## Features

* Semantic HTML
* Education section
* Skills section
* Experience section
* SEO meta tags
* Open Graph tags
* Favicon

## How to Run

Open `index.html` in any web browser.
